# Chemical Engineering Toolkit

## Developed by
**Fedesa Belete**

## Version
1.0

## Description

Chemical Engineering Toolkit is a Python-based application designed to help Chemical Engineering students perform common engineering calculations quickly and easily.

The project combines programming and chemical engineering concepts into one interactive toolkit.

## Features

### General Tools
- Basic Calculator
- Unit Converter
- Calculation History
- About Section

### Fluid Mechanics

- Velocity

### Thermodynamics

### Material Balance

### Heat Transfer
